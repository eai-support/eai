# Mintlify-Equivalence Rubric

| Area | Weight | Score | Evidence |
| --- | ---: | ---: | --- |
| Visual hierarchy and responsive design | 20 | 18 | Enterprise AI design system, responsive home page, improved navigation |
| Task-led information architecture | 15 | 15 | Three primary journeys and focused reference links |
| Search and discovery | 15 | 12 | Generated 15-guide local index, ranked client search, keyboard access |
| Documentation assistant | 10 | 6 | Source-linked static helper; no model-backed answers |
| API developer experience | 10 | 7 | Safe curl generator; no authenticated request execution |
| Content governance and release alignment | 15 | 15 | Existing release assets plus generator and CI validation |
| Feedback and learning loop | 5 | 3 | Configurable privacy-preserving feedback link; no managed analytics |
| Agent experience | 10 | 7 | Existing LLM bundles and JSON guidance; no hosted MCP server |
| **Total** | **100** | **83** | **Strong owned Docusaurus experience; not a claim of feature parity with Mintlify.** |

## Path to 95+

1. Add authenticated, governed search telemetry and feedback storage.
2. Add a backend-backed assistant with citations, rate limits, and evaluation.
3. Add an authenticated API explorer that uses short-lived scoped credentials.
4. Add a hosted MCP server and pull-request preview deployments.
