# EAI CLI Help Snapshot
Version: 3.6.1

Install / update the CLI:
npm config set @eai-tools:registry https://eai-tools.github.io/eai/registry/ --location=user
npm install -g @eai-tools/cli

eai --help
==========

Usage: eai [options] [command]

Enterprise AI Platform CLI — scaffold, seed, deploy, and manage applications

Options:
  -V, --cli-version      output the version number
  --simple               Plain text output without colors or symbols (for screen
                         readers)
  --no-color             Disable colored output
  --color                Force colored output
  --profile <name>       Use a locally configured private profile
  --describe             Output JSON schema of all commands
  -h, --help             display help for command

Commands:
  init [options] [name]  Scaffold a new application
  dev [options]          Start local development server
  login [options]        Authenticate with Entra CIAM
  logout                 Clear stored authentication tokens
  env                    Manage environment variables
  types                  Manage Object Type definitions
  tenant                 Manage tenants on the platform
  user                   Manage users on the platform
  resources              CRUD operations on platform resources
  app|vertical           Manage apps under the active company tenant
  chat                   Chat with AI workflows
  workflow               Provision app workflow configs and inspect AI runtime
                         workflow bindings
  docs                   Document upload, classification, and indexing
  deploy                 Deployment management
  runtime                Validate the provider-neutral EAI app runtime contract
  verify [options]       Run platform connectivity checks
  doctor [options]       Diagnose common issues and suggest fixes
  whoami                 Show auth status and tenant info
  update [options]       Check for and install CLI updates
  provision              Provision platform resources for this app
  gofer                  Inspect and refresh Gofer-managed project assets
  template               Preview application template and UI component drift for
                         the current project
  blocks                 Discover AI-readable EAI UI block manifests
  publicapi              Call authorized PublicAPI V4 routes directly
  errors                 Explain EAI CLI errors and agent-safe recovery steps
  agent                  Show AI-agent discovery and recovery guidance
  help [command]         display help for command

Getting Started:
  eai init my-app     Scaffold an app with Gofer AI CLI assets
  eai login                Authenticate with Entra CIAM
  eai provision entra      Create Entra app registration for end-user auth
  eai env pull             Sync app config from cloud
  eai types seed           Publish Object Types to the platform
  eai dev                  Start local development server

Development Workflows:
  # Define your types, validate them, then publish them
  eai types validate && eai types seed

  # See what is published for the active tenant
  eai resources schema
  eai app create "My App" --template eai-app-template

  # Query resources and inspect data
  eai resources list User --limit 10
  eai resources get User <id>

  # Check AI runtime workflow readiness before using chat
  eai workflow readiness strategy-monitor
  eai workflow status strategy-monitor
  eai workflow request strategy-monitor --reason "CEO strategy cockpit"

  # Check login, tenant, and API connectivity
  eai verify && eai doctor

Deployment:
  # Validate the host-neutral runtime contract before deploying
  eai runtime validate
  eai deploy env --provider generic

  # Set up GitHub Actions deployment
  eai deploy setup --repo org/name

  # Trigger deployment, check status, then doctor the deployed runtime
  eai deploy trigger && eai deploy status
  eai deploy doctor --url <deployed-url>

Machine-Readable Output:
  # Get structured JSON output for automation
  eai resources list User --format json
  eai tenant list --format json | jq
  eai verify calls --format json
  eai errors explain E101 --format json

  # Discover CLI structure for AI agents
  eai --describe
  eai agent guide --format json

AI Terminal Workflows:
  # New projects include Gofer commands, agents, scripts, hooks, and skills
  claude                   then run /0_business_scenario
  codex                    then ask Codex to use the 1_gofer_research skill
  gemini                   then run /gofer:1_gofer_research
  copilot                  uses .github/prompts and .github/skills

Updates:
  # Check/update the CLI, then maintain safe repo-local assets
  eai update --check       preview CLI, Gofer, and template status
  eai update               update the CLI and refresh safe Gofer assets

  # Preview repo-local Gofer asset updates before writing files
  eai gofer refresh --check preview managed Gofer asset updates for this repo
  eai gofer refresh        apply safe Gofer-managed asset updates with backups

  # Preview app-template and UI component drift before copying changes
  eai template check       review potential app or UI file updates without overwriting local work

  # Discover AI-readable UI blocks for Gofer and apps
  eai blocks list --readiness public-ready
                                  list foundation, product, addon, and demo block IDs
  eai blocks describe core.button
  eai blocks readiness     summarize public readiness and package-profile compatibility

  # Call any authorized PublicAPI V4 interface
  eai publicapi get /v4/identity/me --format json
  eai publicapi post /v4/geo/resolve-location --data '{"query":"Copenhagen"}'

  # Explain known errors for humans and AI agents
  eai errors list
  eai errors explain tenant_authorization_incomplete --format json

  # Follow the built-in AI-agent recovery loop
  eai agent guide

Accessibility:
  # Screen reader friendly output
  eai --simple <command>
  eai --no-color <command>

eai update --help
=================

Usage: eai update [options]

Check for and install CLI updates

Options:
  --check               Only check for updates without installing
  --no-project-refresh  Skip Gofer/app-template maintenance for the current
                        project
  -h, --help            display help for command

Examples:
  $ eai update --check
  $ eai update

Notes:
  - The CLI installs from the scoped EAI static registry on GitHub Pages.
  - One-time setup for manual installs: npm config set @eai-tools:registry https://eai-tools.github.io/eai/registry/ --location=user
  - `eai update --check` previews CLI, Gofer, and app-template status without writing files.
  - `eai update` upgrades the CLI, refreshes safe Gofer-managed files in the current EAI project, and reports app-template drift.
  - Use `eai gofer refresh --check` to preview Gofer-managed file changes separately.
  - App-template and UI files are not auto-merged; use `eai template check` to review them.
  - If npm hits a permissions error, the CLI explains how to retry on your platform.

eai doctor --help
=================

Usage: eai doctor [options]

Diagnose common issues and suggest fixes

Options:
  --fix            Attempt to fix issues automatically (default: false)
  --check-updates  Report CLI release status plus Gofer/template drift for the
                   current project (default: false)
  -h, --help       display help for command

Examples:
  $ eai doctor
  $ eai doctor --check-updates

Notes:
  - `eai update` upgrades the installed CLI package only.
  - `eai gofer refresh --check` previews safe repo-local Gofer asset updates.
  - `eai template check` previews app-template and UI drift without writing files.
  - Template and UI component changes are not auto-merged into existing repos yet.

eai errors explain --help
=========================

Usage: eai errors explain [options] <code-or-reason>

Explain why an error happens and what eai commands can recover it

Options:
  --format <format>  Output format (text|json) (default: "text")
  --json             Output raw JSON (deprecated, use --format json) (default:
                     false)
  -h, --help         display help for command

Examples:
  $ eai errors explain E101
  $ eai errors explain tenant_authorization_incomplete
  $ eai errors explain E242 --format json

Notes:
  - Guidance is public-safe and avoids private platform implementation detail.
  - Commands marked [read-only] should run before commands marked [changes state].
  - AI agents should respect retry and stop conditions instead of looping.

eai template check --help
=========================

Usage: eai template check [options]

Preview file-level template/UI drift without writing to the repo

Options:
  --format <format>  Output format (text|json) (default: "text")
  -h, --help         display help for command

Typical workflow:
  eai doctor --check-updates
  eai template check

Notes:
  - This command never writes files to your repo.
  - Template/UI updates still require manual review and selective copy/diff.
  - Use `eai gofer refresh --check` separately for Gofer-managed assets.
