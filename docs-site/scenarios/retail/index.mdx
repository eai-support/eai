Retail systems often need operational workflows that connect products, inventory, suppliers, and customers. These scenarios show how to model those flows with reusable object types and actions.



<!-- four-step-index-note:start -->
## Four-Step Pattern

Every detailed scenario in this library is now framed as the same four-step application pattern:

1. Capture demand and context.
2. Prepare the decision.
3. Execute and collaborate.
4. Resolve, explain, and improve.

Each scenario page calls out the goal of each step, the data needed to achieve it, the AI support that improves the experience, the business impact, and whether the current EAI delivery model is sufficient or needs extension.

## Typical Retail Building Blocks

- Products, stock, orders, returns, suppliers, and loyalty members
- Store, region, or brand-level tenant isolation
- Document workflows for compliance packs and supplier paperwork
- AI support for classification, product summaries, and issue triage
