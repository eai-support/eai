## Persona

**Role:** Supply Chain Analyst at a specialty retail company.

You manage inventory across 12 warehouse locations and 45 retail stores. Each location maintains independent stock levels, and reorder decisions are currently made by store managers using intuition rather than data. Stockouts on popular items cost sales, while overstocking on slow movers ties up capital. You need a centralized system that connects stock data, reorder logic, and supplier performance.

## Business Problem

Stock visibility is siloed by location. Store managers email the central warehouse when they run low, but there is no automated reorder trigger. Supplier lead times are tracked informally, and there is no systematic way to evaluate supplier performance. You need:

- Real-time stock tracking by product and location with reorder point thresholds.
- Automated reorder requests that route to the correct supplier.
- Supplier profiles with lead time and performance rating data.

## Object Types

| Name | Key Properties | Links | Actions |
|------|---------------|-------|---------|
| **StockItem** | product, location, quantity, reorderPoint | has many ReorderRequests | update-quantity, set-reorder-point, flag-low-stock |
| **ReorderRequest** | item, quantity, supplier, status | belongs to StockItem, links to Supplier | create, approve, fulfill, cancel |
| **Supplier** | name, contact, leadTime, rating | has many ReorderRequests | onboard, update-rating, deactivate |

## CLI Workflow

<Steps>

1. **Scaffold the vertical**

   ```bash
   eai init inventory-management
   ```

2. **Authenticate and pull environment**

   ```bash
   eai login
   eai env pull --include-secrets
   ```

   <Aside type="note">
     If you are an external developer, see [Configuration](/docs/configuration) and [Environment Profiles](/docs/profiles) for login and local environment setup.
   </Aside>

3. **Define Object Types**

   Add StockItem, ReorderRequest, and Supplier to `src/eai.config/object-types.ts`.

4. **Validate and seed**

   ```bash
   eai types validate
   eai types seed
   ```

   ```
   Tenant: inventory-management
   ✔ StockItem — 4 props, 1 link, 3 actions
   ✔ ReorderRequest — 4 props, 2 links, 4 actions
   ✔ Supplier — 4 props, 1 link, 3 actions

   ✔ All Object Types are valid
   ```

5. **Add a stock item**

   ```bash
   eai resources create StockItem \
     --data '{"product": "Organic Coffee Beans 1kg", "location": "Warehouse-Central", "quantity": 240, "reorderPoint": 50}'
   ```

6. **Create a reorder request**

   ```bash
   eai resources create ReorderRequest \
     --data '{"item": "stock-001", "quantity": 500, "supplier": "supplier-green-valley", "status": "pending"}'
   ```

7. **List low-stock items**

   ```bash
   eai resources list StockItem --filter 'quantity<50'
   ```

8. **Start local development**

   ```bash
   eai dev
   ```

</Steps>

## Key Takeaways

- **Reorder point thresholds automate replenishment.** Each StockItem carries a reorderPoint, enabling automated low-stock detection and reorder request generation.
- **Supplier-linked reorder requests streamline procurement.** ReorderRequests reference both the StockItem and the Supplier, creating a clear path from stock need to vendor fulfillment.
- **Supplier performance tracking informs sourcing decisions.** The rating field on Suppliers provides data-driven input for contract renewals and vendor consolidation.
- **Location-level visibility eliminates guesswork.** Tracking stock by product and location enables analysts to identify imbalances and optimize distribution across the network.
