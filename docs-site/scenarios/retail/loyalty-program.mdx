## Persona

**Role:** Loyalty Program Director at a regional retail chain.

You manage a customer rewards program across 80 stores. Members earn points on purchases, advance through tiers based on spending, and redeem points for discounts and exclusive products. The existing program runs on a legacy vendor platform with limited flexibility -- adding new reward types requires a multi-week vendor engagement.

## Business Problem

The legacy platform charges per-transaction fees that scale poorly, does not support custom tier rules, and provides limited visibility into member behavior. Marketing wants to launch seasonal promotions and partner rewards, but the vendor's configuration options are too rigid. You need:

- A flexible member registry with tier management and point balances.
- Transaction-level point tracking that supports multiple earning sources.
- A reward catalog with availability controls and dynamic point costs.

- **Goal:** Turn the captured context into the next best action for Loyalty Program without forcing the human reviewer to assemble the case manually.
- **Required data:** Member state and history.
- **AI support:** Run background summarisation, extraction, classification, recommendation drafting, and answer generation so a reviewer sees a prepared case instead of raw fragments. EAI delivers the structured records and AI workflow hooks for this today; specialised scoring engines, external rules, or advanced reasoning controls may still need integration work.
- **Business impact:** Reduce cycle time, improve quality and consistency, and protect the mission-critical metric before the case moves into execution.
- **EAI delivery:** Link records across the scenario, persist decision state as resources, and use workflow actions plus chat assistance to keep humans in control while AI prepares the work.

- **Goal:** Coordinate the actual work, handoffs, approvals, and user updates needed to deliver the service or outcome.

## Object Types

| Name | Key Properties | Links | Actions |
|------|---------------|-------|---------|
| **Member** | customer, tier, points, joinDate | has many PointTransactions | enroll, upgrade-tier, deactivate |
| **PointTransaction** | member, amount, source, description | belongs to Member | earn, redeem, adjust |
| **Reward** | name, pointsCost, category, availability | (standalone) | create, update-availability, retire |

## CLI Workflow

<Steps>

1. **Scaffold the app**

   ```bash
   eai init loyalty-program
   ```

2. **Authenticate and pull environment**

   ```bash
   eai login
   eai env pull --include-secrets
   ```

   <Aside type="note">
     If you are an external developer, see [Configuration](/docs/configuration) for login and local environment setup.
   </Aside>

3. **Define Object Types**

   Add Member, PointTransaction, and Reward to `src/eai.config/object-types.ts`.

4. **Validate and seed**

   ```bash
   eai types validate
   eai types seed
   ```

   ```
   Tenant: loyalty-program
   ✔ Member — 4 props, 1 link, 3 actions
   ✔ PointTransaction — 4 props, 1 link, 3 actions
   ✔ Reward — 4 props, 0 links, 3 actions

   ✔ All Object Types are valid
   ```

5. **Enroll a member**

   ```bash
   eai resources create Member \
     --data '{"customer": "maria.garcia@example.com", "tier": "silver", "points": 0, "joinDate": "2026-03-01"}'
   ```

6. **Record a point transaction**

   ```bash
   eai resources create PointTransaction \
     --data '{"member": "member-001", "amount": 150, "source": "purchase", "description": "In-store purchase at Downtown location"}'
   ```

7. **List available rewards**

   ```bash
   eai resources list Reward --filter 'availability=available'
   ```

8. **Start local development**

   ```bash
   eai dev
   ```

</Steps>

## Key Takeaways

- **Flexible tier management.** Member tiers are defined as select options, making it straightforward to add new tiers or adjust the tier structure without schema changes.
- **Multi-source point earning.** PointTransactions track the source of every point change, enabling marketing to measure which earning channels drive the most engagement.
- **Reward catalog independence.** Rewards are standalone objects with availability controls, allowing the marketing team to launch, limit, and retire rewards without affecting member records.
- **Full transaction history.** Every point earn, redeem, and adjustment is recorded, providing the audit trail needed for financial reconciliation and fraud detection.
