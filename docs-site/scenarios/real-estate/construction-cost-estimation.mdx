## Business Problem

Estimating teams work across drawings, specifications, takeoffs, vendor quotes, subcontractor bids, contingencies, alternates, and bid approvals. The workflow is detail-heavy and changes rapidly as packages evolve.

## Delivery Workflow

1. Authenticate and choose the tenant you want to work in.

   ```bash
   eai login
   eai tenant select
   ```

2. Pull environment values, validate the type definitions, and seed the model.

   ```bash
   eai env pull --include-secrets
   eai types validate
   eai types seed
   ```

3. Verify that the full model is available for the active tenant before building UI and workflows.

   ```bash
   eai resources schema --format json
   eai verify calls --format json
   ```

4. Load pilot data and exercise the operational workflows for the scenario.

## AI and Document Opportunities

- Classify drawings and specifications into the right work-breakdown structure.
- Summarise estimate changes between versions and highlight cost drivers before bid submission.
- Generate benchmark comparisons and risk notes from prior awards, vendor quotes, and alternates.

## Why This Scenario Is High-Value

Estimating teams need more than spreadsheets when bid volume rises. This scenario gives preconstruction teams a repeatable way to manage pricing, assumptions, and review discipline.
