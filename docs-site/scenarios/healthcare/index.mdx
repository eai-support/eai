Healthcare delivery depends on clinical workflows, administrative coordination, payer interaction, and strict data handling. This library now includes both patient-facing workflows and back-office healthcare operations.



<!-- four-step-index-note:start -->
## Four-Step Pattern

Every detailed scenario in this library is now framed as the same four-step application pattern:

1. Capture demand and context.
2. Prepare the decision.
3. Execute and collaborate.
4. Resolve, explain, and improve.

Each scenario page calls out the goal of each step, the data needed to achieve it, the AI support that improves the experience, the business impact, and whether the current EAI delivery model is sufficient or needs extension.

## Typical Building Blocks

- Patients, providers, encounters, authorisations, claims, inventory, and credentialing records
- Tenant-aware workflows for hospitals, clinics, departments, and care networks
- Document workflows for referrals, authorisations, notes, and compliance records
- AI support for triage, summarisation, classification, and work-queue prioritisation
