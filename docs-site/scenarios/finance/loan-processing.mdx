## Persona

**Role**: Solutions architect at a community credit union consortium (12 credit unions, 300 employees total) building a shared loan origination platform.

Each credit union operates as a separate tenant with its own underwriting criteria and member data. The shared platform reduces development costs while maintaining complete data isolation between institutions.

## Business Problem

Loan applications move through multiple stages -- intake, credit evaluation, underwriting, and disbursement -- often across disconnected spreadsheets and email threads. Loan officers lack real-time visibility into application status, and credit check results are manually copied between systems. This scenario builds a structured loan processing pipeline where applications flow from submission through approval to disbursement with full traceability.

## Four-Step Application

This scenario works best as a four-step, human-in-the-loop application. The existing object model already gives this scenario a strong delivery backbone through LoanApplication, CreditCheck, and Disbursement.

- **Mission metric focus:** faster cycle time, better compliance quality, and stronger revenue or loss performance.
- **Human + AI pattern:** Each step combines structured workflow data with chat assistance, background generation, document understanding, and accessible interaction patterns when they improve the experience.

### Step 1. Capture demand and context

- **Goal:** Make it easy for the user to start the Loan Processing journey with complete, trusted context.
- **Required data:** LoanApplication context such as applicant, amount, term, and purpose.
- **AI support:** Use chat to guide intake, generate clearer prompts, create accessible summaries, and assist with voice or vision-led capture when a form alone is not the best experience. EAI can support structured intake, chat workflows, and document-centred capture today; richer native multimodal capture may still need workflow extensions or connected services.
- **Business impact:** Improve completion rate, reduce first-touch effort, and raise customer or staff confidence in the UX from the very first interaction.
- **EAI delivery:** Model the intake as tenant-isolated object types and resources, then use actions, chat workflows, and document indexing or classification to keep the initial record complete and usable.

### Step 2. Prepare the decision

- **Goal:** Turn the captured context into the next best action for Loan Processing without forcing the human reviewer to assemble the case manually.
- **Required data:** LoanApplication state and history; CreditCheck fields such as score, report, date, and bureau.
- **AI support:** Run background summarisation, extraction, classification, recommendation drafting, and answer generation so a reviewer sees a prepared case instead of raw fragments. EAI delivers the structured records and AI workflow hooks for this today; specialised scoring engines, external rules, or advanced reasoning controls may still need integration work.
- **Business impact:** Reduce cycle time, improve quality and consistency, and protect the mission-critical metric before the case moves into execution.
- **EAI delivery:** Link records across the scenario, persist decision state as resources, and use workflow actions plus chat assistance to keep humans in control while AI prepares the work.

### Step 3. Execute and collaborate

- **Goal:** Coordinate the actual work, handoffs, approvals, and user updates needed to deliver the service or outcome.
- **Required data:** CreditCheck actions such as runCreditCheck; Disbursement fields such as amount, method, date, and status.
- **AI support:** Draft replies, produce work packets, monitor exceptions in the background, and surface the next action for each operator. EAI can orchestrate tenant-isolated records, actions, chats, and document workflows today; deeper system-to-system automation may require additional connectors or workflow capability.
- **Business impact:** Increase operator productivity, reduce rework across handoffs, and improve service consistency across the application journey.
- **EAI delivery:** Use linked object types, actions, resource updates, and workflow-triggered AI assistance so the team can execute in one model instead of splitting work across disconnected tools.

### Step 4. Resolve, explain, and improve

- **Goal:** Close the loop with a clear outcome, an understandable explanation, and feedback that improves the next case.
- **Required data:** final status, outcome, audit history, and follow-up signals across LoanApplication, CreditCheck, and Disbursement.
- **AI support:** Generate outcome summaries, customer-friendly answers, compliance-ready notes, management insights, and accessible follow-up content. EAI can store outcome records and support answer generation today, while richer proactive agents, advanced analytics, or channel-specific accessibility features may need additional product capability.
- **Business impact:** Increase trust, quality, and measurable business value through faster cycle time, better compliance quality, and stronger revenue or loss performance.
- **EAI delivery:** Keep the full audit trail in structured resources, use AI workflows to explain outcomes, and feed the resulting signals into future product, service, and operational improvement work.

## Object Types

| Name | Key Properties | Links | Actions |
|------|---------------|-------|---------|
| **LoanApplication** | `applicant` (text), `amount` (number), `term` (number), `purpose` (select: home, auto, personal, business), `status` (select: submitted, under-review, approved, denied, disbursed) | one-to-many → CreditCheck, one-to-many → Disbursement | `reviewApplication` |
| **CreditCheck** | `score` (number), `report` (text), `date` (date), `bureau` (text), `debtToIncomeRatio` (number) | many-to-one → LoanApplication | `runCreditCheck` |
| **Disbursement** | `amount` (number), `method` (select: ach, wire, check), `date` (date), `status` (select: pending, processed, failed), `referenceNumber` (text) | many-to-one → LoanApplication | `processDisbursement` |

## CLI Workflow

<Steps>

1. **Scaffold the project**

   ```bash
   eai init loan-processing
   ```

2. **Authenticate and pull environment**

   ```bash
   eai login
   eai env pull --include-secrets
   ```

   <Aside type="note">
     If you are an external developer, see [Configuration](/docs/configuration) and [Environment Profiles](/docs/profiles) for login and local environment setup.
   </Aside>

3. **Define your Object Types**

   Create the LoanApplication, CreditCheck, and Disbursement types in `src/eai.config/object-types.ts` (see code example below).

4. **Validate the type definitions**

   ```bash
   eai types validate
   ```

   ```
   Tenant: loan-processing
   ✔ LoanApplication — 5 props, 2 links, 1 action
   ✔ CreditCheck — 5 props, 1 link, 1 action
   ✔ Disbursement — 5 props, 1 link, 1 action

   ✔ All Object Types are valid
   ```

5. **Seed types to the platform**

   ```bash
   eai types seed
   ```

6. **Create a sample loan application**

   ```bash
   eai resources create LoanApplication --data '{"applicant": "Maria Gonzalez", "amount": 25000, "term": 60, "purpose": "auto", "status": "submitted"}'
   ```

7. **Query applications by status**

   ```bash
   eai resources list LoanApplication
   ```

8. **Start local development**

   ```bash
   eai dev
   ```

</Steps>

## Key Takeaways

- **Full origination pipeline**: The LoanApplication, CreditCheck, and Disbursement types model the complete loan lifecycle from submission through funds transfer, replacing fragmented spreadsheet workflows.
- **Credit check integration**: The `runCreditCheck` action captures bureau-specific scores and debt-to-income ratios, giving underwriters structured data for consistent decision-making.
- **Consortium model**: Each credit union operates in its own tenant with independent underwriting criteria, while sharing the same platform infrastructure and codebase to reduce costs.
- **Disbursement traceability**: Every fund transfer is recorded with method, reference number, and status, providing a complete audit trail from approval to payment.
