## Install

Configure npm to use the EAI registry, then install:

```bash
echo "@eai-tools:registry=https://eai-tools.github.io/eai-cli/registry" >> ~/.npmrc
npm install -g @eai-tools/cli
```

## Quick Workflow

```bash
# Scaffold a new vertical application
eai init my-vertical
cd my-vertical && npm install

# Authenticate and sync environment
eai login
eai env pull --include-secrets

# Define your data model, validate, and publish
eai types validate
eai types seed

# Start developing
eai dev
```
