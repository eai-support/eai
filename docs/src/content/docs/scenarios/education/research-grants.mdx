## Persona

**Role:** Research Administration Officer at a research university.

You support faculty across 12 departments in preparing grant proposals, managing awarded funds, and ensuring compliance with sponsor requirements. The university submits over 300 proposals per year to federal agencies, foundations, and industry partners. Each awarded grant comes with its own budget structure, reporting requirements, and spending rules.

## Business Problem

Proposal tracking is fragmented -- principal investigators (PIs) manage their own submissions in personal spreadsheets, and the grants office learns about awards only when PIs forward notification emails. Budget tracking for active awards is done in a separate financial system that is not linked to the original proposal. Spending overruns on individual budget categories go undetected until quarterly reconciliation. You need:

- A centralized proposal registry with PI, agency, and status tracking.
- Award records linked to funded proposals with start and end dates.
- Budget items that track allocated versus spent amounts by category.

## Object Types

| Name | Key Properties | Links | Actions |
|------|---------------|-------|---------|
| **Proposal** | title, pi, agency, amount, status | has one Award | submit, revise, withdraw |
| **Award** | proposal, amount, startDate, endDate | belongs to Proposal, has many BudgetItems | activate, extend, close |
| **BudgetItem** | award, category, allocated, spent | belongs to Award | allocate, spend, reallocate |

## CLI Workflow

<Steps>

1. **Scaffold the vertical**

   ```bash
   eai init research-grants
   ```

2. **Authenticate and pull environment**

   ```bash
   eai login
   eai env pull --include-secrets
   ```

   <Aside type="note">
     If you are an external developer, see [External Developer Setup](/eai-cli/guides/external-developers/) for login flags and manual environment configuration.
   </Aside>

3. **Define Object Types**

   Add Proposal, Award, and BudgetItem to `src/eai.config/object-types.ts`.

4. **Validate and seed**

   ```bash
   eai types validate
   eai types seed
   ```

   ```
   Tenant: research-grants
   ✔ Proposal — 5 props, 1 link, 3 actions
   ✔ Award — 4 props, 2 links, 3 actions
   ✔ BudgetItem — 4 props, 1 link, 3 actions

   ✔ All Object Types are valid
   ```

5. **Create a proposal**

   ```bash
   eai resources create Proposal \
     --data '{"title": "Machine Learning for Climate Modeling", "pi": "Dr. Elena Vasquez", "agency": "nsf", "amount": 450000, "status": "submitted"}'
   ```

6. **Record an award**

   ```bash
   eai resources create Award \
     --data '{"proposal": "prop-001", "amount": 450000, "startDate": "2026-09-01", "endDate": "2029-08-31"}'
   ```

7. **Add a budget item**

   ```bash
   eai resources create BudgetItem \
     --data '{"award": "award-001", "category": "personnel", "allocated": 280000, "spent": 0}'
   ```

8. **Start local development**

   ```bash
   eai dev
   ```

</Steps>

## Key Takeaways

- **Centralized proposal tracking improves institutional visibility.** The grants office can see all proposals across departments, enabling better resource allocation and avoiding duplicate submissions to the same program.
- **Award-to-proposal linking maintains the funding trail.** Every Award traces back to its originating Proposal, making it easy to compile success rates by PI, department, or funding agency.
- **Category-level budget monitoring catches overruns early.** Tracking allocated versus spent amounts on each BudgetItem allows administrators to flag spending issues before they escalate to sponsor audit findings.
- **Agency-based filtering supports compliance.** Different funding agencies have different reporting and spending rules; filtering by agency helps the grants office apply the correct compliance framework to each award.
