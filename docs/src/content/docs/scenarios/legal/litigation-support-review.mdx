## Business Problem

Litigation support teams need to preserve evidence, coordinate collections, manage review batches, track privilege, prepare productions, and control vendor spend. The workflow is high risk and highly document-centric.

## Required Object Model (22 object types)

This scenario needs more than 20 object types because it spans intake, delivery, exceptions, governance, and reporting.

### Preservation and Collection

- `Matter` — litigation matter
- `Custodian` — custodian record
- `CollectionSource` — collection source
- `PreservationNotice` — preservation notice
- `EvidenceSet` — evidence collection
- `ReviewBatch` — review batch
- `ReviewTag` — review coding tag
- `PrivilegeDecision` — privilege decision

### Case Preparation

- `HotDocument` — key document
- `Deposition` — deposition record
- `Witness` — witness record
- `TimelineEvent` — case timeline event
- `FactIssue` — fact or legal issue
- `MotionDraft` — motion draft
- `ExhibitList` — exhibit set
- `Hearing` — hearing record

### Production and Vendor Oversight

- `OutsideCounselInvoice` — outside counsel invoice
- `BudgetTracker` — budget record
- `VendorWorkOrder` — vendor assignment
- `QAException` — quality exception
- `ProductionSet` — production package
- `ProductionLog` — production audit log

## Delivery Workflow

1. Authenticate and choose the tenant you want to work in.

   ```bash
   eai login
   eai tenant select
   ```

2. Pull environment values, validate the type definitions, and seed the model.

   ```bash
   eai env pull --include-secrets
   eai types validate
   eai types seed
   ```

3. Verify that the full model is available for the active tenant before building UI and workflows.

   ```bash
   eai resources schema --format json
   eai verify calls --format json
   ```

4. Load pilot data and exercise the operational workflows for the scenario.

## AI and Document Opportunities

- Classify evidence sets into the right review batches and issue groupings.
- Summarise review progress, privilege hotspots, and production readiness for case teams.
- Generate witness-prep and hearing packets from facts, exhibits, and hot documents.

## Why This Scenario Is High-Value

Litigation support becomes unmanageable when preservation, review, and production live in separate systems. This scenario provides one operational spine for matter teams and vendors.
