## Persona

**Role**: Developer at a 50-attorney law firm transitioning from legacy billing software.

Attorneys log time in personal notebooks or desktop timers and submit entries weekly. Billing rates vary by attorney, matter type, and client arrangement, but are tracked in a separate spreadsheet. Invoices are generated manually by the billing department, requiring reconciliation of time entries against rate tables. The firm needs an integrated system where time entry, rates, and invoicing are connected.

## Business Problem

Revenue leakage is the firm's biggest financial problem. Attorneys forget to log time, entries are submitted late with inaccurate descriptions, and the billing department spends days each month reconciling entries against the correct rates. Client disputes over invoices require pulling original time entries from multiple systems. This scenario builds a billing workflow that captures time entries linked to cases, applies the correct billing rates automatically, and generates invoices with line-item detail.

## Object Types

| Name | Key Properties | Links | Actions |
|------|---------------|-------|---------|
| **TimeEntry** | `attorney` (text), `case` (text), `date` (date), `hours` (number), `description` (text), `status` (select: draft, submitted, billed) | many-to-one → Invoice | `submitEntry` |
| **BillingRate** | `attorney` (text), `type` (select: standard, discounted, pro-bono, contingency), `rate` (number), `effectiveDate` (date) | -- | -- |
| **Invoice** | `client` (text), `totalAmount` (number), `status` (select: draft, sent, paid, overdue, disputed), `dueDate` (date), `sentDate` (date) | one-to-many → TimeEntry | `sendInvoice` |

## CLI Workflow

<Steps>

1. **Scaffold the project**

   ```bash
   eai init billing-time-tracking
   ```

2. **Authenticate and pull environment**

   ```bash
   eai login
   eai env pull --include-secrets
   ```

   <Aside type="note">
     If you are an external developer, see [External Developer Setup](/eai-cli/guides/external-developers/) for login flags and manual environment configuration.
   </Aside>

3. **Define your Object Types**

   Create the TimeEntry, BillingRate, and Invoice types in `src/eai.config/object-types.ts` (see code example below).

4. **Validate the type definitions**

   ```bash
   eai types validate
   ```

   ```
   Tenant: billing-time-tracking
   ✔ TimeEntry — 6 props, 1 link, 1 action
   ✔ BillingRate — 4 props, 0 links, 0 actions
   ✔ Invoice — 5 props, 1 link, 1 action

   ✔ All Object Types are valid
   ```

5. **Seed types to the platform**

   ```bash
   eai types seed
   ```

6. **Create sample resources**

   ```bash
   eai resources create TimeEntry --data '{"attorney": "Lisa Park", "case": "Smith v. Acme Industries", "date": "2025-07-15", "hours": 2.5, "description": "Draft motion for summary judgment", "status": "draft"}'
   ```

7. **Start local development**

   ```bash
   eai dev
   ```

</Steps>

```typescript
export const objectTypes = {
  'billing-time-tracking': [

      name: 'TimeEntry',
      displayName: 'Time Entry',
      description: 'A billable time entry recorded by an attorney',

        { name: 'attorney', type: 'text' as const, required: true, indexed: true },
        { name: 'case', type: 'text' as const, required: true, indexed: true },
        { name: 'date', type: 'date' as const, required: true, indexed: true },
        { name: 'hours', type: 'number' as const, required: true },
        { name: 'description', type: 'text' as const, required: true },
        { name: 'status', type: 'select' as const, required: true, defaultValue: 'draft', options: [
          { label: 'Draft', value: 'draft' },

        { name: 'attorney', type: 'text' as const, required: true, indexed: true },
        { name: 'type', type: 'select' as const, required: true, options: [
          { label: 'Standard', value: 'standard' },
          { label: 'Discounted', value: 'discounted' },
          { label: 'Pro Bono', value: 'pro-bono' },
          { label: 'Contingency', value: 'contingency' },
        ]},
        { name: 'rate', type: 'number' as const, required: true },
        { name: 'effectiveDate', type: 'date' as const, required: true, indexed: true },
      ],
      linkTypes: [],
      actions: [],

    {
      name: 'Invoice',

```

## Key Takeaways

- **Revenue capture**: Structured time entry submission with required descriptions reduces forgotten or under-documented billable time.
- **Rate management**: Billing rates are stored per attorney with effective dates, supporting rate changes and multiple arrangement types without manual lookups.
- **Invoice line-item detail**: Invoices link directly to their constituent time entries, making client disputes easy to resolve with original entry data.
- **Billing lifecycle**: Time entries flow from draft through submission to billed, and invoices move from draft through sent to paid, giving the billing department complete pipeline visibility.
