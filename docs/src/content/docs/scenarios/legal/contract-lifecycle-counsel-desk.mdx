## Business Problem

In-house counsel desks receive contract requests that need intake triage, templating, negotiation, approvals, signatures, obligation tracking, and renewals. When those steps are fragmented, business teams experience delays and legal loses visibility.

## Required Object Model (22 object types)

This scenario needs more than 20 object types because it spans intake, delivery, exceptions, governance, and reporting.

### Request and Drafting Context

- `Requester` — business requester
- `ContractRequest` — contract intake request
- `Counterparty` — counterparty record
- `Template` — approved template
- `ClauseLibrary` — reusable clause library
- `RiskProfile` — matter risk profile
- `ApprovalStep` — approval stage
- `NegotiationRound` — negotiation cycle

### Execution and Oversight

- `RedlineArtifact` — redline file
- `SignaturePacket` — execution packet
- `Obligation` — post-signature obligation
- `RenewalNotice` — renewal event
- `PlaybookRule` — review playbook rule
- `LegalIssue` — open legal issue
- `PolicyException` — approved policy exception
- `VendorScreening` — vendor screening case

### Risk and Audit

- `PrivacyAssessment` — privacy review
- `SecurityAssessment` — security review
- `Amendment` — contract amendment
- `Task` — work item
- `AuditLog` — audit record
- `ReportView` — operational reporting view

## Delivery Workflow

1. Authenticate and choose the tenant you want to work in.

   ```bash
   eai login
   eai tenant select
   ```

2. Pull environment values, validate the type definitions, and seed the model.

   ```bash
   eai env pull --include-secrets
   eai types validate
   eai types seed
   ```

3. Verify that the full model is available for the active tenant before building UI and workflows.

   ```bash
   eai resources schema --format json
   eai verify calls --format json
   ```

4. Load pilot data and exercise the operational workflows for the scenario.

## AI and Document Opportunities

- Classify contract requests by request type, risk level, and template fit.
- Summarise redline rounds and highlight clauses outside the approved playbook.
- Generate obligation and renewal watchlists from executed contracts and amendments.

## Why This Scenario Is High-Value

Contract desks need speed without sacrificing control. A dedicated lifecycle model gives legal, procurement, security, and privacy teams one shared workflow instead of parallel approval chains.
