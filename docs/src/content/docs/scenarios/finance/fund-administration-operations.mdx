## Business Problem

Fund administration requires precise coordination across investors, share classes, transfer activity, valuations, fees, compliance, and reporting. Without a connected operating model, teams struggle to keep investor service, NAV production, and oversight aligned.

## Required Object Model (23 object types)

This scenario needs more than 20 object types because it spans intake, delivery, exceptions, governance, and reporting.

### Fund and Investor Administration

- `Fund` — fund master record
- `ShareClass` — investor share class
- `Investor` — investor account
- `SubscriptionOrder` — subscription request
- `RedemptionOrder` — redemption request
- `TransferRequest` — transfer request
- `CapitalCall` — capital call notice
- `DistributionNotice` — distribution notice

### Valuation and Holdings

- `NAVPackage` — net asset value package
- `PortfolioHolding` — fund holding record
- `SecurityMaster` — security reference data
- `TradeCapture` — trade record
- `CashReconciliation` — cash position reconciliation
- `ValuationSource` — price or valuation source
- `FeeSchedule` — fee configuration
- `WaterfallRule` — distribution waterfall rule

### Compliance and Investor Service

- `ComplianceBreach` — breach or exception
- `SideLetter` — investor side-letter terms
- `KYCProfile` — investor due-diligence profile
- `AMLAlert` — AML review alert
- `TransferAgentTask` — investor service task
- `StatementRun` — investor statement cycle
- `AuditRequest` — external audit support request

## Delivery Workflow

1. Authenticate and choose the tenant you want to work in.

   ```bash
   eai login
   eai tenant select
   ```

2. Pull environment values, validate the type definitions, and seed the model.

   ```bash
   eai env pull --include-secrets
   eai types validate
   eai types seed
   ```

3. Verify that the full model is available for the active tenant before building UI and workflows.

   ```bash
   eai resources schema --format json
   eai verify calls --format json
   ```

4. Load pilot data and exercise the operational workflows for the scenario.

## AI and Document Opportunities

- Classify subscription and redemption documents before transfer-agent review.
- Summarise side-letter obligations, compliance breaches, and unresolved KYC alerts.
- Generate investor-service worklists tied to statement runs, transfers, and audit requests.

## Why This Scenario Is High-Value

Fund administration is a coordination-heavy business where operational mistakes quickly become client and regulatory problems. This scenario gives administrators a reusable operating model across multiple funds and service lines.
