## Persona

**Role:** Records Management Specialist at a federal agency.

You oversee the agency's public records program, which includes cataloging government documents, processing Freedom of Information Act (FOIA) requests, and coordinating redactions with legal counsel. The volume of FOIA requests has grown steadily, and your team struggles to meet statutory response deadlines with manual tracking.

## Business Problem

Records are scattered across network drives with inconsistent metadata. FOIA requests arrive via email and are tracked in a spreadsheet that frequently falls out of date. Redaction decisions are communicated verbally, leaving no documentation of what was redacted or why. You need:

- A centralized records catalog with classification and retention metadata.
- Structured FOIA request tracking with deadline enforcement.
- Redaction records that document which sections were withheld and the legal basis.

## Object Types

| Name | Key Properties | Links | Actions |
|------|---------------|-------|---------|
| **Record** | title, category, classification, retentionDate | has many Redactions | publish, archive, reclassify |
| **FOIARequest** | requester, description, status, dueDate | links to Records | receive, assign, fulfill, deny |
| **Redaction** | record, reason, redactedBy, sections | belongs to Record | apply, review, approve |

## CLI Workflow

<Steps>

1. **Scaffold the vertical**

   ```bash
   eai init public-records
   ```

2. **Authenticate and pull environment**

   ```bash
   eai login
   eai env pull --include-secrets
   ```

3. **Define Object Types**

   Add Record, FOIARequest, and Redaction to `src/eai.config/object-types.ts`.

4. **Validate and seed**

   ```bash
   eai types validate
   eai types seed
   ```

   ```
   Tenant: public-records
   ✔ Record — 4 props, 1 link, 3 actions
   ✔ FOIARequest — 4 props, 1 link, 4 actions
   ✔ Redaction — 4 props, 1 link, 3 actions

   ✔ All Object Types are valid
   ```

5. **Create a record**

   ```bash
   eai resources create Record \
     --data '{"title": "FY2025 Budget Memo", "category": "financial", "classification": "public", "retentionDate": "2032-09-30"}'
   ```

6. **Create a FOIA request**

   ```bash
   eai resources create FOIARequest \
     --data '{"requester": "J. Smith", "description": "All budget memos from FY2025", "status": "received", "dueDate": "2026-04-08"}'
   ```

7. **List pending FOIA requests**

   ```bash
   eai resources list FOIARequest --filter 'status=received'
   ```

8. **Start local development**

   ```bash
   eai dev
   ```

</Steps>

## Key Takeaways

- **Classification-aware records management.** Every record carries a classification level, ensuring sensitive documents are handled appropriately during FOIA processing.
- **Deadline-driven FOIA tracking.** The dueDate field on FOIARequest enables automated alerts and dashboards that prevent statutory deadline violations.
- **Documented redaction decisions.** Each Redaction captures the legal basis and affected sections, providing a defensible record if a denial is appealed.
- **Retention policy enforcement.** The retentionDate property on Records allows automated archival workflows that align with federal records schedules.
