## Persona

**Role:** Grants Program Manager at a state economic development agency.

You administer multiple grant programs that fund community development, small business growth, and workforce training. Each program receives hundreds of applications per cycle. Once grants are awarded, your team must track milestone-based disbursements and collect impact reports from grantees. The current system is a patchwork of forms, email, and manual ledger entries.

## Business Problem

Grant applications arrive through different channels with no standardized format. Disbursement tracking is done in spreadsheets that are not linked to the original applications, making it difficult to verify that funds are released against completed milestones. Impact reports are submitted as unstructured documents with no consistent metrics. You need:

- A unified application intake tied to specific grant programs.
- Milestone-based disbursement tracking linked to awarded grants.
- Structured impact reporting with quantifiable metrics and narrative context.

## Object Types

| Name | Key Properties | Links | Actions |
|------|---------------|-------|---------|
| **GrantApplication** | program, applicant, amount, status | has many Disbursements, has many ImpactReports | submit, review, award, reject |
| **Disbursement** | grant, amount, milestone, date | belongs to GrantApplication | request, approve, release |
| **ImpactReport** | grant, period, metrics, narrative | belongs to GrantApplication | submit, review, accept |

## CLI Workflow

<Steps>

1. **Scaffold the vertical**

   ```bash
   eai init grant-management
   ```

2. **Authenticate and pull environment**

   ```bash
   eai login
   eai env pull --include-secrets
   ```

3. **Define Object Types**

   Add GrantApplication, Disbursement, and ImpactReport to `src/eai.config/object-types.ts`.

4. **Validate and seed**

   ```bash
   eai types validate
   eai types seed
   ```

   ```
   Tenant: grant-management
   ✔ GrantApplication — 4 props, 2 links, 4 actions
   ✔ Disbursement — 4 props, 1 link, 3 actions
   ✔ ImpactReport — 4 props, 1 link, 3 actions

   ✔ All Object Types are valid
   ```

5. **Create a grant application**

   ```bash
   eai resources create GrantApplication \
     --data '{"program": "Small Business Growth Fund", "applicant": "Downtown Bakery LLC", "amount": 25000, "status": "submitted"}'
   ```

6. **Track a disbursement**

   ```bash
   eai resources create Disbursement \
     --data '{"grant": "app-001", "amount": 10000, "milestone": "Equipment Purchase", "date": "2026-04-15"}'
   ```

7. **List awarded grants**

   ```bash
   eai resources list GrantApplication --filter 'status=awarded'
   ```

8. **Start local development**

   ```bash
   eai dev
   ```

</Steps>

## Key Takeaways

- **Milestone-based disbursements prevent premature payouts.** Each Disbursement is tied to a specific milestone, ensuring funds are released only when deliverables are verified.
- **Structured impact reporting enables program evaluation.** Standardized metrics fields make it possible to compare outcomes across grantees and programs.
- **End-to-end grant lifecycle tracking.** From application through disbursement to impact reporting, every stage is captured in a single system with clear status transitions.
- **Program-level visibility.** Filtering applications by program and status gives program managers an at-a-glance view of portfolio health across all active grant cycles.
