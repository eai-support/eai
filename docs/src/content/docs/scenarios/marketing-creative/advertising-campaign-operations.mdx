## Business Problem

Advertising teams must connect the brief, budget, audience, creative, channel plan, approvals, launch, optimisation, and reporting. A structured vertical makes it easier to manage campaign operations across clients and channels.

## Required Object Model (22 object types)

This scenario needs more than 20 object types because it spans intake, delivery, exceptions, governance, and reporting.

### Campaign Setup

- `Client` — client account
- `Brand` — brand record
- `CampaignBrief` — campaign brief
- `AudienceSegment` — target audience
- `ChannelPlan` — channel plan
- `Budget` — campaign budget
- `CreativeConcept` — creative concept
- `CreativeAsset` — creative asset

### Execution and Measurement

- `CopyVariant` — copy variation
- `Approval` — approval step
- `MediaInsertionOrder` — media order
- `Publisher` — publisher or platform
- `Flight` — campaign flight
- `PerformanceMetric` — tracked KPI
- `Lead` — campaign lead
- `ConversionEvent` — conversion event

### Optimisation and Finance

- `Experiment` — test or experiment
- `ComplianceReview` — brand or legal review
- `Invoice` — campaign invoice
- `Reconciliation` — spend reconciliation
- `OptimizationTask` — optimisation task
- `PostCampaignReport` — post-campaign report

## Delivery Workflow

1. Authenticate and choose the tenant you want to work in.

   ```bash
   eai login
   eai tenant select
   ```

2. Pull environment values, validate the type definitions, and seed the model.

   ```bash
   eai env pull --include-secrets
   eai types validate
   eai types seed
   ```

3. Verify that the full model is available for the active tenant before building UI and workflows.

   ```bash
   eai resources schema --format json
   eai verify calls --format json
   ```

4. Load pilot data and exercise the operational workflows for the scenario.

## AI and Document Opportunities

- Classify briefs and creative feedback into the right campaign and asset threads.
- Summarise channel performance and suggest optimisation tasks from conversion and spend signals.
- Generate post-campaign reports by combining approvals, assets, flights, and KPI outcomes.

## Why This Scenario Is High-Value

Campaign operations are difficult because creative, media, and reporting all move at different speeds. This scenario gives marketing teams a shared operational model instead of disconnected specialist tools.
