## Business Problem

Design studios move from brief to research, wireframes, systems, prototypes, usability review, and handoff with many revisions in between. A dedicated workflow model keeps design work and client decision points visible.

## Required Object Model (22 object types)

This scenario needs more than 20 object types because it spans intake, delivery, exceptions, governance, and reporting.

### Research and Framing

- `ClientProject` — design project
- `DesignBrief` — project brief
- `ResearchPlan` — research plan
- `InterviewNote` — research interview note
- `Persona` — target persona
- `JourneyMap` — journey map
- `Sitemap` — information architecture
- `Wireframe` — wireframe artefact

### Design and Review

- `DesignSystemToken` — design token
- `ComponentLibrary` — component library
- `Prototype` — prototype
- `FeedbackRound` — feedback cycle
- `UsabilityTest` — usability test
- `Defect` — design issue
- `Revision` — revision record
- `HandoffPackage` — handoff package

### Commercial and Portfolio Output

- `AssetExport` — asset export
- `ApprovalGate` — approval gate
- `VendorIllustrationTask` — vendor artwork task
- `BudgetLine` — project budget
- `Milestone` — delivery milestone
- `CaseStudy` — published case study

## Delivery Workflow

1. Authenticate and choose the tenant you want to work in.

   ```bash
   eai login
   eai tenant select
   ```

2. Pull environment values, validate the type definitions, and seed the model.

   ```bash
   eai env pull --include-secrets
   eai types validate
   eai types seed
   ```

3. Verify that the full model is available for the active tenant before building UI and workflows.

   ```bash
   eai resources schema --format json
   eai verify calls --format json
   ```

4. Load pilot data and exercise the operational workflows for the scenario.

## AI and Document Opportunities

- Classify research notes and feedback into personas, journeys, and design issues.
- Summarise revision history and unresolved defects before handoff.
- Generate case-study summaries from briefs, prototypes, outcomes, and approvals.

## Why This Scenario Is High-Value

Creative delivery is often harder to supervise than it looks. This scenario helps studios manage research, production, and client approvals in one coherent workflow.
