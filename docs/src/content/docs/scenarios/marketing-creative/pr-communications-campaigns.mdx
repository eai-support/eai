## Business Problem

PR teams work across campaign narratives, media lists, pitches, spokesperson preparation, crisis responses, and coverage reporting. A workflow platform helps them manage relationship-heavy operations with better discipline.

## Required Object Model (22 object types)

This scenario needs more than 20 object types because it spans intake, delivery, exceptions, governance, and reporting.

### Campaign and Messaging Setup

- `Client` — client account
- `Campaign` — PR campaign
- `Narrative` — campaign narrative
- `MessageHouse` — message architecture
- `Spokesperson` — spokesperson profile
- `MediaList` — target media list
- `Journalist` — journalist record
- `Pitch` — outbound pitch

### Execution and Response

- `CoverageItem` — earned coverage
- `PressRelease` — press release
- `Event` — campaign event
- `BriefingNote` — briefing note
- `Approval` — approval step
- `CrisisIssue` — crisis issue
- `ResponsePlan` — response plan
- `SentimentSignal` — sentiment signal

### Amplification and Reporting

- `SocialPost` — amplification post
- `KPIReport` — performance report
- `AssetPack` — campaign asset pack
- `StakeholderUpdate` — stakeholder update
- `Budget` — campaign budget
- `FollowUpTask` — follow-up action

## Delivery Workflow

1. Authenticate and choose the tenant you want to work in.

   ```bash
   eai login
   eai tenant select
   ```

2. Pull environment values, validate the type definitions, and seed the model.

   ```bash
   eai env pull --include-secrets
   eai types validate
   eai types seed
   ```

3. Verify that the full model is available for the active tenant before building UI and workflows.

   ```bash
   eai resources schema --format json
   eai verify calls --format json
   ```

4. Load pilot data and exercise the operational workflows for the scenario.

## AI and Document Opportunities

- Classify media responses, coverage, and social reactions into the right campaign threads.
- Summarise briefing materials and crisis developments for spokesperson and leadership prep.
- Generate campaign performance updates from coverage, sentiment, and follow-up activity.

## Why This Scenario Is High-Value

Communications teams need speed and control at the same time. This scenario helps them manage complex campaigns and crisis workflows without losing context.
