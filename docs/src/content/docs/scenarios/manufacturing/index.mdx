## Typical Manufacturing Building Blocks

- Production runs, equipment, defects, inspections, and supplier records
- Plant, line, or business-unit tenant separation
- Document workflows for inspection reports, manuals, and certificates
- AI support for issue triage, summarisation, and document processing
