## Business Problem

Credentialing teams need to track provider licenses, certifications, sanctions checks, references, enrolments, committee reviews, and reappointment cycles. The workflow spans many deadlines and evidence types, making spreadsheet-based operations risky.

## Required Object Model (22 object types)

This scenario needs more than 20 object types because it spans intake, delivery, exceptions, governance, and reporting.

### Provider Profile and Evidence

- `Provider` — provider record
- `Specialty` — clinical specialty
- `Facility` — credentialed facility
- `PayerEnrollment` — payer enrolment
- `License` — professional license
- `Certification` — board or training certificate
- `MalpracticePolicy` — malpractice cover
- `WorkHistory` — professional history

### Verification and Review

- `ReferenceCheck` — reference review
- `SanctionsCheck` — sanctions screening
- `CredentialingPacket` — credentialing bundle
- `CommitteeReview` — committee case
- `ApprovalDecision` — credentialing decision
- `ReappointmentCycle` — reappointment workflow
- `ExpirationAlert` — upcoming expiry alert
- `DelegatedGroup` — delegated credentialing group

### Roster and Governance

- `RosterSubmission` — payer roster submission
- `RosterResponse` — payer roster response
- `AuditFinding` — credentialing audit finding
- `ContractTerm` — contractual requirement
- `AccessRole` — system access entitlement
- `TrainingCompletion` — required training completion

## Delivery Workflow

1. Authenticate and choose the tenant you want to work in.

   ```bash
   eai login
   eai tenant select
   ```

2. Pull environment values, validate the type definitions, and seed the model.

   ```bash
   eai env pull --include-secrets
   eai types validate
   eai types seed
   ```

3. Verify that the full model is available for the active tenant before building UI and workflows.

   ```bash
   eai resources schema --format json
   eai verify calls --format json
   ```

4. Load pilot data and exercise the operational workflows for the scenario.

## AI and Document Opportunities

- Classify provider documents and identify missing expiries or mismatched credentials.
- Summarise open credentialing packets before committee review.
- Generate renewal and enrolment worklists from expiries, payer rosters, and audit findings.

## Why This Scenario Is High-Value

Credentialing delays affect revenue, staffing, and compliance all at once. A structured platform helps health systems keep clinicians active while reducing manual follow-up and expiry risk.
