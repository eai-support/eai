## Typical Healthcare Building Blocks

- Patients, providers, appointments, referrals, and assessments
- Role-based access for clinics, departments, or hospital groups
- Document workflows for forms, referrals, and clinical records
- AI-assisted triage, summarisation, and classification where appropriate
