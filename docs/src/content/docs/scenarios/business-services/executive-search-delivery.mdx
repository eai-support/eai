## Business Problem

Executive search firms manage long-cycle mandates with research, target mapping, discreet outreach, assessments, shortlist reviews, and placement governance. The process needs more structure than a basic ATS can provide.

## Required Object Model (22 object types)

This scenario needs more than 20 object types because it spans intake, delivery, exceptions, governance, and reporting.

### Mandate and Research Setup

- `SearchMandate` — retained search mandate
- `Client` — client organisation
- `TargetCompany` — target organisation
- `TargetProfile` — ideal candidate profile
- `ResearchList` — research universe
- `Prospect` — target prospect
- `OutreachTouch` — outreach interaction
- `Longlist` — longlist candidate set

### Assessment and Decisioning

- `Shortlist` — shortlist candidate set
- `Assessment` — candidate assessment
- `InterviewBrief` — client interview brief
- `CompensationBenchmark` — compensation benchmark
- `CandidateDossier` — candidate dossier
- `OffLimitsRule` — off-limits constraint
- `MarketMap` — market map
- `ReferenceInterview` — reference interview

### Placement and Governance

- `OfferStrategy` — offer strategy
- `Placement` — final placement
- `RetainedMilestone` — retained-fee milestone
- `GuaranteePeriod` — placement guarantee period
- `SearchTeamTask` — team task
- `WinLossReview` — win-loss review

## Delivery Workflow

1. Authenticate and choose the tenant you want to work in.

   ```bash
   eai login
   eai tenant select
   ```

2. Pull environment values, validate the type definitions, and seed the model.

   ```bash
   eai env pull --include-secrets
   eai types validate
   eai types seed
   ```

3. Verify that the full model is available for the active tenant before building UI and workflows.

   ```bash
   eai resources schema --format json
   eai verify calls --format json
   ```

4. Load pilot data and exercise the operational workflows for the scenario.

## AI and Document Opportunities

- Summarise research findings and candidate dossiers before client shortlist reviews.
- Classify outreach responses and reference interviews into structured candidate signals.
- Generate market-map and off-limits insight from prior mandates and target-company overlap.

## Why This Scenario Is High-Value

Executive search is a knowledge-intensive service with high client expectations. This scenario helps firms systematise delivery without losing the nuance needed for senior placements.
