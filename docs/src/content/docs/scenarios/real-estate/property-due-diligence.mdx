description: Coordinate lease, compliance, capex, and risk review for acquisitions or portfolio decisions.

## Business Problem

Property diligence requires teams to review leases, inspections, environmental issues, utilities, contracts, rent rolls, capex items, and compliance issues before acquisition or refinancing decisions. The workflow spans many specialists and evidence packs.

## Required Object Model (22 object types)

This scenario needs more than 20 object types because it spans intake, delivery, exceptions, governance, and reporting.

### Portfolio Review Context

- `PortfolioReview` — portfolio review record
- `Property` — property record
- `OwnershipEntity` — ownership entity
- `LeaseAbstract` — lease abstract
- `Tenant` — tenant record
- `RentRoll` — rent-roll snapshot
- `SiteInspection` — site inspection
- `EnvironmentalReport` — environmental report

### Risk Review and Evidence

- `ZoningCheck` — zoning review
- `CapexItem` — capital expenditure item
- `InsuranceReview` — insurance review
- `ServiceContract` — service contract
- `UtilityAccount` — utility record
- `ComplianceIssue` — compliance issue
- `LitigationFlag` — litigation flag
- `VendorTask` — external review task

### Decision Support

- `DataRoomItem` — data-room artefact
- `RiskScore` — aggregated risk score
- `Recommendation` — investment recommendation
- `InvestmentCommitteeMemo` — committee memo
- `PurchaseCondition` — purchase condition
- `ClosingTask` — close transaction task

## Delivery Workflow

1. Authenticate and choose the tenant you want to work in.

   ```bash
   eai login
   eai tenant select
   ```

2. Pull environment values, validate the type definitions, and seed the model.

   ```bash
   eai env pull --include-secrets
   eai types validate
   eai types seed
   ```

3. Verify that the full model is available for the active tenant before building UI and workflows.

   ```bash
   eai resources schema --format json
   eai verify calls --format json
   ```

4. Load pilot data and exercise the operational workflows for the scenario.

## AI and Document Opportunities

- Classify diligence documents by property, lease, contract, or compliance topic.
- Summarise high-risk findings and unresolved diligence tasks for committee review.
- Generate closing and remediation worklists from the final recommendation and purchase conditions.

## Why This Scenario Is High-Value

Property decisions are only as strong as the diligence process behind them. This scenario creates a structured record of what was reviewed, what was found, and what still needs action.
