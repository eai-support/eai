## Business Problem

Architecture teams move from proposal to design, coordination, approvals, and construction administration with many stakeholders and revisions. A vertical application helps firms keep every deliverable, issue, and approval in sync.

## Required Object Model (23 object types)

This scenario needs more than 20 object types because it spans intake, delivery, exceptions, governance, and reporting.

### Project Setup and Scope

- `Client` — client organisation
- `Project` — project record
- `Site` — project site
- `Proposal` — proposal record
- `Contract` — engagement contract
- `ScopePackage` — scope definition
- `DesignPhase` — design phase
- `RequirementBrief` — requirements brief

### Design and Coordination

- `DrawingSet` — drawing package
- `Revision` — drawing revision
- `CoordinationIssue` — interdiscipline issue
- `Submittal` — submittal record
- `RFI` — request for information
- `Consultant` — external consultant
- `Discipline` — discipline team
- `BudgetEstimate` — design-stage estimate

### Approvals and Construction Admin

- `ScheduleBaseline` — project schedule baseline
- `PermitApplication` — permit submission
- `Approval` — authority or client approval
- `ConstructionAdminTask` — construction admin task
- `MeetingMinute` — meeting record
- `ChangeDirective` — site change directive
- `CloseoutPackage` — project closeout pack

## Delivery Workflow

1. Authenticate and choose the tenant you want to work in.

   ```bash
   eai login
   eai tenant select
   ```

2. Pull environment values, validate the type definitions, and seed the model.

   ```bash
   eai env pull --include-secrets
   eai types validate
   eai types seed
   ```

3. Verify that the full model is available for the active tenant before building UI and workflows.

   ```bash
   eai resources schema --format json
   eai verify calls --format json
   ```

4. Load pilot data and exercise the operational workflows for the scenario.

## AI and Document Opportunities

- Classify RFIs, submittals, and meeting minutes into the right project and phase.
- Summarise coordination issues and pending approvals before design reviews.
- Generate construction administration worklists from changes, site issues, and closeout requirements.

## Why This Scenario Is High-Value

Architecture delivery depends on controlled revisions and coordinated stakeholder decisions. This scenario provides firms with a structured operating model from concept through closeout.
