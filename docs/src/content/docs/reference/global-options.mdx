## Synopsis

All commands start with the same CLI shell:

```bash
eai [global-options] <command> [command-options]
```

Global options apply before the command name. They change how the CLI behaves overall, not what a specific command does.

## Shared Global Flags

| Flag | What it does |
|------|---------------|
| `--describe` | Print the full CLI schema as JSON for automation or AI tools |
| `--simple` | Use plain text output without symbols or styling |
| `--no-color` | Disable ANSI colors |
| `--color` | Force ANSI colors |
| `-V, --version` | Print the installed CLI version |
| `-h, --help` | Show help |

## Examples

### Show the installed version

```bash
eai --version
```

Example output:

```text
0.3.3
```

### Show help

```bash
eai --help
```

Use this when you want a quick overview of the available commands and common workflows.

### Output the CLI schema as JSON

```bash
eai --describe
```

This is useful for:

- AI coding agents that need to discover the command surface
- automation that validates the CLI structure
- scripts that want to inspect commands and options programmatically

### Use simple output

```bash
eai --simple verify
```

This replaces symbols and styling with plain text, which is easier for:

- screen readers
- pasted logs
- terminals where styling gets in the way

### Control color output

```bash
eai --no-color resources list User
eai --color resources list User
```

Use `--no-color` when saving logs or piping to tools that do not handle ANSI escapes well. Use `--color` when piping to a pager like `less -R`.

## Common Command-Specific Output Flags

`--format json` is **not** a global option. It is provided by many data-returning commands such as:

- `eai tenant list`
- `eai resources list`
- `eai resources get`
- `eai deploy status`
- `eai verify calls`

Example:

```bash
eai resources list User --format json
```

Some commands also still accept `--json` as a legacy alias for `--format json`.

## Environment Variables

The CLI respects the standard color-control environment variables:

| Variable | Effect |
|----------|--------|
| `NO_COLOR=1` | Disable colors globally |
| `FORCE_COLOR=1` | Force colors globally |

Command-line flags take precedence over the environment variables.

## Combining Flags

You can combine global flags with command-specific options:

```bash
eai --simple resources list User --format json
eai --no-color verify
eai --color docs classify ./contract.pdf
```
