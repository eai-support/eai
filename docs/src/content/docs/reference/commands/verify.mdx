## Synopsis

```
eai verify
eai verify calls [options]
```

## Description

`eai verify` runs a series of connectivity and configuration checks against the EAI platform. It validates that your local environment can communicate with the API gateway, that authentication is working, that platform services are reachable, and that your local Object Types are loadable.

This command is useful after initial setup, when debugging connectivity issues, or before deploying to confirm your environment is healthy.

The command must be run from within an EAI project directory and requires `BASE_URL_PUBLIC_API` to be set in `.env.local` or the environment.

`eai verify calls` performs a contract audit of the platform-facing API routes the CLI depends on. It safely exercises read-only endpoints by default, reports mutation-heavy routes as intentionally skipped, and can optionally probe resource, tenant, user, and chat routes when you provide IDs or opt in.

## Checks Performed

| Check | What it verifies |
|-------|-----------------|
| **API gateway** | The PublicAPI endpoint is reachable (HTTP request to `/health`). Reports latency. |
| **Authentication** | A valid authentication token exists in `~/.eai/`. Shows the authenticated user. |
| **Platform service** | The platform service responds to Object Type queries (requires auth + tenant ID). |
| **Data service** | The data service schema endpoint is reachable. Reports the number of published types. |
| **Local Object Types** | `src/eai.config/object-types.ts` is loadable and reports type/tenant counts. |

Checks 3 and 4 (platform service and data service) are only run if authentication is valid and a tenant ID is available.

## Troubleshooting

| Failure | Resolution |
|---------|------------|
| PublicAPI not reachable | Check `BASE_URL_PUBLIC_API` in `.env.local`. Run `eai env pull` to sync. Verify network connectivity. |
| Not authenticated | Run `eai login` to authenticate with Entra CIAM. |
| Platform service not reachable | Confirm your tenant ID is correct. Check `TENANT_*_ID` in `.env.local`. |
| Data service returned error | The tenant may not have published types yet. Run `eai types seed` to publish. |
| No Object Types found | Create or fix `src/eai.config/object-types.ts`. Run `eai init` for a scaffold. |
| Contract audit route failed | The backend route or response shape changed. Compare the failing endpoint in `eai verify calls` with the corresponding command implementation before shipping. |
