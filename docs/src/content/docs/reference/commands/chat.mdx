## Synopsis

```
eai chat <subcommand> <message> [options]
```

## Description

`eai chat` interacts with AI workflows on the EAI platform. You can send single messages and receive a complete response, or stream a conversation using Server-Sent Events (SSE) for real-time output.

Each chat message is associated with a workflow, a stage within that workflow, and a conversation ID. The conversation ID allows you to continue a multi-turn conversation across multiple commands.

This command requires `BASE_URL_PUBLIC_API` and a tenant ID to be set in `.env.local` or the environment.

## Subcommands

### eai chat send

Send a single message and receive the full response at once.

```
eai chat send <message> [options]
```

| Option | Description | Default |
|--------|-------------|---------|
| `<message>` | The message to send | Required |
| `--workflow <id>` | Workflow ID (required) | Required |
| `--stage <stage>` | Chat stage within the workflow | `chat` |
| `--conversation <id>` | Conversation ID for multi-turn conversations. Auto-generated if omitted. | Auto-generated UUID |

### eai chat stream

Stream a conversation in real-time using SSE. Tokens are printed to stdout as they arrive.

```
eai chat stream <message> [options]
```

| Option | Description | Default |
|--------|-------------|---------|
| `<message>` | The initial message to send | Required |
| `--workflow <id>` | Workflow ID (required) | Required |
| `--stage <stage>` | Chat stage within the workflow | `chat` |
| `--conversation <id>` | Conversation ID for multi-turn conversations. Auto-generated if omitted. | Auto-generated UUID |

## Examples

### Send a single message

```bash
eai chat send "What documents are required for a new patient intake?" \
  --workflow wf-abc-123
```

```
ℹ Conversation: 7e2a4f6b-c8d9-4321-abcd-ef0123456789

{
  "response": "For a new patient intake, the following documents are typically required:\n\n1. Photo ID (driver's license or passport)\n2. Insurance card (front and back)\n3. Completed patient registration form\n4. Medical history questionnaire\n5. Signed consent forms",
  "conversationId": "7e2a4f6b-c8d9-4321-abcd-ef0123456789",
  "stage": "chat"
}
```

### Stream a conversation

```bash
eai chat stream "Summarize the latest claims for region West" \
  --workflow wf-claims-456
```

```
ℹ Streaming conversation: a1b2c3d4-e5f6-7890-abcd-ef1234567890

Based on the latest data, here are the claims for the West region:

1. **Claim #W-2024-001** — $12,500 — Status: Under Review
   Filed by: Acme Corp on March 1, 2026

2. **Claim #W-2024-002** — $8,200 — Status: Approved
   Filed by: Widget Inc on February 28, 2026

3. **Claim #W-2024-003** — $45,000 — Status: Pending Documentation
   Filed by: GlobalTech on February 25, 2026

Total claims value: $65,700 across 3 active claims.

✔ Stream complete
```

### Continue an existing conversation

```bash
eai chat send "Tell me more about claim W-2024-003" \
  --workflow wf-claims-456 \
  --conversation a1b2c3d4-e5f6-7890-abcd-ef1234567890
```

### Use a specific stage

```bash
eai chat stream "Generate a summary report" \
  --workflow wf-reports-789 \
  --stage report-generation
```

### Pipe the response for downstream processing

```bash
eai chat send "List all overdue tasks as JSON" \
  --workflow wf-tasks-101 | jq '.response'
```

## Workflow and Stage

- **Workflow**: Identifies the AI configuration to use (model, system prompt, tools, RAG settings). Workflow IDs are provisioned on the platform and stored in your `.env.local` as `WORKFLOW_*_ID`.
- **Stage**: A named phase within a workflow. The default stage is `chat`. Other stages might include `triage`, `classification`, `report-generation`, etc.
- **Conversation ID**: Groups messages into a single conversation context. The AI retains memory of previous messages within the same conversation ID.
