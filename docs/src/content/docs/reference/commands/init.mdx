## Synopsis

```
eai init [name] [options]
```

## Description

`eai init` scaffolds a new vertical application from the [Vertical-Template](https://github.com/eai-tools/Vertical-Template). It clones the template, customizes configuration files, generates an Object Types scaffold, sets up a deployment workflow, and initializes a fresh git repository.

If `name` is not provided on the command line, the CLI will prompt for it interactively along with other configuration options such as display name, tenant structure, and feature selection.

The generated project is a Next.js 15 application with EAI platform integration, including:

- A pre-configured `.env.local` with placeholder values
- An Object Types scaffold in `src/eai.config/object-types.ts`
- A GitHub Actions deployment workflow in `.github/workflows/deploy-demo.yml`
- A `CLAUDE.md` project reference file
- An initial git commit

## Options

| Option | Description | Default |
|--------|-------------|---------|
| `[name]` | Name for the vertical (kebab-case). Prompted interactively if omitted. | -- |
| `--from <repo>` | GitHub repo URL or local path for the template. | `https://github.com/eai-tools/Vertical-Template.git` |
| `--skip-prompts` | Use defaults without interactive prompts. Requires `name` argument. | `false` |
| `-h, --help` | Display help for the command. | -- |

### Interactive Prompts

When running without `--skip-prompts`, the CLI will ask:

| Prompt | Description | Default |
|--------|-------------|---------|
| Vertical name | kebab-case identifier (e.g., `patient-intake`) | Value of `[name]` argument |
| Display name | Human-readable name (e.g., `Patient Intake`) | Derived from vertical name |
| Description | Short description of the application | `<Display Name> vertical application` |
| Tenant structure | Single tenant, dual tenant, or multi-tenant hierarchy | Single tenant |
| Include AI chat? | Whether to include AI chat features | Yes |
| Include document management? | Whether to include document upload/classification | Yes |
| Auth provider | Entra ID CIAM, Entra ID B2B, or Dual | CIAM |

### Scaffold with interactive prompts

```bash
eai init
```

? Tenant structure: Single tenant (most common)
? Include AI chat? Yes
? Include document management? Yes
? Auth provider: Entra ID CIAM (recommended)

✔ Generated .env.local

### Scaffold with name argument

```bash
eai init claims-processing
```

The CLI skips the name prompt and proceeds to the remaining interactive prompts.

### Scaffold with all defaults (no prompts)

```bash
eai init claims-processing --skip-prompts
```

### Scaffold from a custom template

```bash
eai init my-vertical --from https://github.com/my-org/my-template.git
```
