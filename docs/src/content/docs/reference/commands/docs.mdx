## Synopsis

```
eai docs <subcommand> <argument> [options]
```

## Description

`eai docs` manages documents on the EAI platform. You can upload files, run document classification, and index documents for retrieval-augmented generation (RAG) so they become searchable by AI chat workflows.

This command uses the active tenant selected through `eai login` and `eai tenant select`. `BASE_URL_PUBLIC_API` can still come from `.env.local` or the environment when needed. The `upload` subcommand also requires valid authentication tokens.

## Subcommands

### eai docs upload

Upload a file to the platform. The file is sent as multipart form data with your bearer token and active tenant context.

```
eai docs upload <file>
```

| Option | Description | Default |
|--------|-------------|---------|
| `<file>` | Path to the file to upload | Required |

### eai docs classify

Run document classification. Depending on the backend, the result may be immediate or it may return a queued job that completes asynchronously.

```
eai docs classify <file>
```

| Option | Description | Default |
|--------|-------------|---------|
| `<file>` | Path to the file to classify | Required |

### eai docs index

Index an uploaded document for RAG (retrieval-augmented generation). Once indexed, the document's content becomes available to AI chat workflows for context-aware responses.

```
eai docs index <documentId>
```

| Option | Description | Default |
|--------|-------------|---------|
| `<documentId>` | The ID of the previously uploaded document | Required |

## Examples

### Upload a document

```bash
eai docs upload ./reports/q1-financial-summary.pdf
```

```text
⠋ Uploading q1-financial-summary.pdf...
✔ Queued q1-financial-summary.pdf for upload (job job-8f3a1b2c) — doc-8f3a1b2c-d4e5-6789-abcd-ef0123456789
```

### Classify a document

```bash
eai docs classify ./reports/q1-financial-summary.pdf
```

```text
⠋ Classifying q1-financial-summary.pdf...
✔ Classified q1-financial-summary.pdf as financial-report (94%) — doc-8f3a1b2c-d4e5-6789-abcd-ef0123456789
```

If your platform classifies asynchronously, the CLI instead reports the queued job and document ID so you can follow up later.

### Index a document for RAG

```bash
eai docs index doc-8f3a1b2c-d4e5-6789-abcd-ef0123456789
```

```
⠋ Indexing document doc-8f3a1b2c-d4e5-6789-abcd-ef0123456789...
✔ Indexed document doc-8f3a1b2c-... for RAG
```

### Full workflow: upload, classify, and index

```bash
# Step 1: Upload the document
eai docs upload ./evidence/patient-lab-results.pdf

# Step 2: Classify the document
eai docs classify ./evidence/patient-lab-results.pdf

# Step 3: Index for RAG (use the document ID from the upload response)
eai docs index doc-a7c9e4d1-b2c3-4567-89ab-cdef01234567

# Step 4: Query via AI chat
eai chat stream "What do the lab results show?" --workflow wf-medical-789
```

## Prerequisites

- **Authentication**: Run `eai login` before uploading documents. Upload requires a valid access token.
- **Tenant context**: Run `eai login` and `eai tenant select` before `classify` or `index`.
- **File access**: The file path must be accessible from the current working directory.
