title: eai update

## Synopsis

```bash
eai update [--check]
```

## Description

`eai update` checks the EAI registry for the latest CLI release and installs it globally for you.

It uses the scoped EAI registry only for `@eai-tools/cli`. Public dependencies such as `chalk` still come from the normal npm registry, which is why the command uses a scoped registry override instead of a full `--registry` replacement.

The CLI also checks for updates in the background during normal use. If a newer version is available, it prints a short reminder after your command finishes.

## Options

| Option | Description |
|--------|-------------|
| `--check` | Check whether a newer version exists, but do not install it |
| `-h, --help` | Show help |

## Examples

### Check without installing

```bash
eai update --check
```

Example output:

```text
✔ Update available: 0.3.2 → 0.3.3
→ Run eai update to install.
```

### Install the latest version

```bash
eai update
```

Example output:

```text
✔ Update available: 0.3.2 → 0.3.3
✔ Updated to 0.3.3
```

### Already on the latest version

```bash
eai update
```

Example output:

```text
✔ Already on the latest version (0.3.3)
```

### Permission error

If npm needs elevated permissions, the CLI prints the exact fallback command:

```text
✖ Update failed.
→ Try with sudo: sudo npm install -g @eai-tools/cli@0.3.3 --@eai-tools:registry=https://eai-tools.github.io/eai-cli/registry
```

## Automatic Update Checks

Automatic checks are:

- cached for 24 hours in `~/.eai/update-check.json`
- skipped in CI
- skipped when `NO_UPDATE_NOTIFIER=1` is set
- skipped when stderr is not a TTY

Example reminder:

```text
  Update available: 0.3.2 → 0.3.3
  Run eai update to update
```
